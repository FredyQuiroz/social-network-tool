# Social Network Tool

[Español](#español) · [English](#english)

## Español

Aplicación de escritorio para organizar fichas personales y volver a encontrar información como áreas de interés, estudios, oficina y residencia.

### Qué puedes hacer

- Registra información de perfiles y sus áreas de interés.
- Consulta las vistas de estudios, oficina y residencia.
- Busca perfiles y revisa cómo se presenta el seguimiento.

### Ejemplo

Usa un perfil ficticio con dos intereses y un estudio, y revisa el recorrido desde su ficha hasta la búsqueda.

### Cómo empezar

El código se creó para Windows y Visual C++. Usa las versiones de MFC o de los SDK que indiquen la solución y sus referencias. Los recursos y componentes externos de la época pueden requerir una copia autorizada. La compilación completa depende de ese entorno original.

Puntos de entrada en el código. [`src/Administrador/Administrador.sln`](src/Administrador/Administrador.sln), [`src/appt/appt.sln`](src/appt/appt.sln), [`src/english/english.sln`](src/english/english.sln), [`src/german/german.sln`](src/german/german.sln).

Las fechas del historial se apoyan en Git o en la evidencia disponible de los respaldos. Las fechas reconstruidas a partir de archivos sin zona horaria usan las 12:00 UTC como referencia.

## English

A desktop application for organizing personal profiles and finding information about interests, education, offices, and residences.

### What you can do

- Record profile information and areas of interest.
- Explore education, office, and residence views.
- Search profiles and see how follow-up information is presented.

### Example

Use a fictional profile with two interests and one education entry, then trace it from its record to search.

### Getting started

The code was written for Windows and Visual C++. Use the MFC and SDK versions indicated by the solution and its references. Historical resources and external components may require an authorized copy. A full build depends on that original environment.

Entry points in the source. [`src/Administrador/Administrador.sln`](src/Administrador/Administrador.sln), [`src/appt/appt.sln`](src/appt/appt.sln), [`src/english/english.sln`](src/english/english.sln), [`src/german/german.sln`](src/german/german.sln).
